## 一、认识 Java

Java 是由 Sun Microsystems 公司于 1995 年 5 月推出的面向对象程序设计语言和 Java 平台的总称，由 James Gosling 和同事共同研发，后来 Sun 公司被 Oracle 收购，Java 成为 Oracle 的产品。

### Java 的特性

**1. 平台无关性（跨平台）**
这是 Java 最核心、最具辨识度的特性，即“一次编写，到处运行”。Java 源代码编译后生成的是与特定硬件和操作系统无关的字节码，只要目标平台安装了对应的 Java 虚拟机（JVM），字节码就能运行。这一机制打破了 C/C++ 依赖特定平台编译的限制，使其能够轻松部署在 Windows、Linux、macOS 等各种系统上。

**2. 面向对象**
Java 是一门纯粹的面向对象语言。除了少数基本数据类型外，Java 中的一切皆为对象。它全面支持封装、继承和多态，强制开发者以模块化和可复用的思维构建软件。与 C++ 不同，Java 去除了多重继承、运算符重载等复杂特性，通过接口实现多继承的灵活性，使语言更简单、更纯粹。

**3. 自动内存管理**
Java 引入了垃圾回收机制（Garbage Collection, GC），由 JVM 自动回收不再被引用的对象所占用的内存。程序员无需像在 C/C++ 中那样手动管理内存的分配与释放，从而有效避免了内存泄漏、悬空指针等导致程序崩溃的问题，大大提升了程序的健壮性和安全性**

### JDK

JDK 全称是 Java Development Kit，即 Java 开发工具包。它是整个 Java 开发的核心，包含了开发 Java 程序所需的各种工具和运行环境

### IntelliJ IDEA

IntelliJ IDEA 是由 JetBrains 公司开发的一款**专业的集成开发环境（IDE）**，主要用于 Java 和 Kotlin 开发，被公认为 Java 领域最强大的开发工具之一

#### 2.1.2 整型

对于整型类型，Java只定义了带符号的整型，因此，最高位的bit表示符号位（0表示正数，1表示负数）。各种整型能表示的最大范围如下，对于long类型，需要加上L后缀：

```java
byte：-128 ~ 127
short: -32768 ~ 32767
int: -2147483648 ~ 2147483647
long: -9223372036854775808 ~ 9223372036854775807

int a = 1
long a = 1000000000001L
```

#### 2.1.3 浮点型

浮点类型的数就是小数，因为小数用科学计数法表示的时候，小数点是可以“浮动”的，所以称为浮点数。对于float类型，需要加上f后缀。浮点数可表示的范围非常大，float类型可最大表示3.4x1038，而double类型可最大表示1.79x10308。

```java
float f1 = 3.14f;
float f2 = 3.14e38f; // 科学计数法表示的3.14x10^38
float f3 = 1.0; // 错误：不带f结尾的是double类型，不能赋值给float

double d1 = 1.79e308;
double d2 = -1.79e308;
double d3 = 4.9e-324;
```

#### 2.1.4 布尔类型

布尔类型boolean只有true和false两个值，布尔类型总是关系运算的计算结果：Java语言对布尔类型的存储并没有做规定，因为理论上存储布尔类型只需要1 bit，但是通常JVM内部会把boolean表示为4字节整数。

```java
boolean b1 = true;
boolean b2 = false;
boolean isGreater = 5 > 3; // 计算结果为true
int age = 12;
boolean isAdult = age >= 18; // 计算结果为false
```

#### 2.1.5 字符类型

字符类型`char`表示一个字符。Java的`char`类型除了可表示标准的ASCII外，还可以表示一个Unicode字符,

注意`char`类型使用单引号`'`，且仅有一个字符，要和双引号`"`的字符串类型区分开。

```java
char a = 'A';
char zh = '中';
```

#### 2.1.6 引用类型

除了上述基本类型的变量，剩下的都是引用类型。例如，引用类型最常用的就是`String`字符串；引用类型的变量类似于C语言的指针，它内部存储一个“地址”，指向某个对象在内存的位置

```java
String s = "hello";
```

#### 2.1.7 常量

定义变量的时候，如果加上`final`修饰符，这个变量就变成了常量，常量在定义时进行初始化后就不可再次赋值，再次赋值会导致编译错误。为了和变量区分开来，根据习惯，常量名通常**全部大写**。

```java
final double PI = 3.14; // PI是一个常量
double r = 5.0;
double area = PI * r * r;
PI = 300; // compile error!
```

#### 2.1.8 `var` 关键字

有些时候，类型的名字太长，写起来比较麻烦。例如：

```java
StringBuilder sb = new StringBuilder();
```

这个时候，如果想省略变量类型，可以使用`var`关键字：

```java
var sb = new StringBuilder();
```

编译器会根据赋值语句自动推断出变量`sb`的类型是`StringBuilder`。对编译器来说，语句：

```java
var sb = new StringBuilder();
```

实际上会自动变成：

```java
StringBuilder sb = new StringBuilder();
```

因此，使用`var`定义变量，仅仅是少写了变量类型而已。

#### 2.1.9 变量的作用范围

Java中，多行语句用`{ ... }`括起来。只要正确地嵌套这些`{ ... }`，编译器就能识别出语句块的开始和结束。而在语句块中定义的变量，它有一个作用域，就是从定义处开始，到语句块结束。超出了作用域引用这些变量，编译器会报错。定义变量时，要遵循作用域最小化原则，尽量将变量定义在尽可能小的作用域，并且，不要重复使用变量名。举个例子：

```java
{
    ...
    int i = 0; // 变量i从这里开始定义
    ...
    {
        ...
        int x = 1; // 变量x从这里开始定义
        ...
        {
            ...
            String s = "hello"; // 变量s从这里开始定义
            ...
        } // 变量s作用域到此结束
        ...
        // 注意，这是一个新的变量s，它和上面的变量同名，
        // 但是因为作用域不同，它们是两个不同的变量:
        String s = "hi";
        ...
    } // 变量x和s作用域到此结束
    ...
} // 变量i作用域到此结束
```

#### 2.2.3 类型转化

**隐式转换**

就是 Java 自动帮你完成类型转换，不需要手动写转换代码。常见整数和浮点数的取值范围关系可以简单记成：

```
byte → short → int → long → float → double
```

原则一：**byte、short、char 参与运算时，会先自动提升为 int。**

原则二：不同类型参与运算时，会把范围小的类型提升成范围大的类型，再进行运算。

**强制类型转换**

当你想把**范围大的类型转换成范围小的类型**时，Java 不会自动转换，需要手动强制转换。

```
格式：目标类型 变量名 = (目标类型) 数据;
double a = 3.14;
int b = (int) a;
System.out.println(b);
3
```

注意，浮点数强制转换成整数时，**不是四舍五入，而是直接舍弃小数部分**；强制转换可能导致数据丢，失超出了范围，所以转换后发生了数据溢出

```java
//整数转换成浮点数
int a = 10;
double b = a;
//浮点数转换成整数
double a = 3.99;
int b = (int) a;//直接截断小数部分
//数字类型之间的转换
int a = 10;
long b = a;
float c = a;
double d = a;
//反过来：
double a = 10.5;
float b = (float) a;
long c = (long) a;
int d = (int) a;
//数字和字符串之间的转换
int a = 123;
String str1 = String.valueOf(a);     // 数字转字符串

String str2 = "456";
int b = Integer.parseInt(str2);      // 字符串转整数

String str3 = "3.14";
double c = Double.parseDouble(str3); // 字符串转小数

//char 和数字之间的转换
char ch1 = 'A';
int num1 = ch1;                      // char 转 int，结果是 65

int num2 = 66;
char ch2 = (char) num2;              // int 转 char，结果是 'B'
```

### 2.3 输入输出

```java
import java.util.Scanner;

public class VariableDemo6 {
    public static void main(String[] args) {
        // ==================== 输入 ====================
        /*
         * Java 输入输出
         *
         * 输入：
         * 1. 导入 Scanner
         * 2. 创建 Scanner 对象
         * 3. 使用 Scanner 接收不同类型的数据
         *
         * 输出：
         * 1. System.out.print()
         * 2. System.out.println()
         * 3. System.out.printf()
         */

        // 1. 创建 Scanner 对象
        Scanner sc = new Scanner(System.in);

        // 2. 输入整数
        int num = sc.nextInt();
        System.out.println(num);

        // 3. 输入小数
        double num2 = sc.nextDouble();
        System.out.println(num2);

        // 4. 输入字符串（遇到空格停止）
        String str = sc.next();
        System.out.println(str);

        // 5. 输入一整行字符串
        String line = sc.nextLine();
        System.out.println(line);

        // 6. 输入单个字符
        char ch = sc.next().charAt(0);
        System.out.println(ch);

        // 7. 一次输入多个整数
        int a = sc.nextInt();
        int b = sc.nextInt();
        int c = sc.nextInt();

        System.out.println(a);
        System.out.println(b);
        System.out.println(c);

        // 8. 多行输入
        for (int i = 0; i < 3; i++) {
            String str = sc.nextLine();
            System.out.println(str);
        }

        // 9. 不知道输入多少行
        while (sc.hasNextLine()) {
            String str = sc.nextLine();
            System.out.println(str);
        }

        // 10. nextInt() 和 nextLine() 混用
        int age = sc.nextInt();
        // 吃掉整数后面剩余的换行符
        sc.nextLine();
        String name = sc.nextLine();
        System.out.println(age);
        System.out.println(name);

        // ==================== 输出 ====================

        // 11. print：输出后不换行
        System.out.print("Hello ");
        System.out.print("Java");
        // 12. println：输出后自动换行
        System.out.println("Hello");
        System.out.println("Java");

        // 13. printf 格式化输出
        String name = "张三";
        System.out.printf("姓名：%s%n", name);

        sc.close();
    }
}
```

## 1. Getting to Know Java

Java is the collective name for the object-oriented programming language and Java platform introduced by Sun Microsystems in May 1995. It was developed by James Gosling and his colleagues. Sun was later acquired by Oracle, and Java became an Oracle product.

### Java Features

**1. Platform Independence (Cross-Platform)**

This is Java's most central and recognizable feature: “write once, run anywhere.” Java source code is compiled into bytecode that is independent of specific hardware and operating systems. As long as the target platform has the corresponding Java Virtual Machine (JVM) installed, the bytecode can run. This mechanism breaks the limitation of C/C++ programs being compiled for specific platforms, allowing Java programs to be easily deployed on Windows, Linux, macOS, and other systems.

**2. Object-Oriented**

Java is a purely object-oriented language. Except for a small number of primitive data types, everything in Java is an object. It fully supports encapsulation, inheritance, and polymorphism, encouraging developers to build software with modularity and reusability in mind. Unlike C++, Java removes complex features such as multiple inheritance and operator overloading. It achieves the flexibility of multiple inheritance through interfaces, making the language simpler and purer.

**3. Automatic Memory Management**

Java introduces a garbage collection mechanism (Garbage Collection, GC). The JVM automatically reclaims memory occupied by objects that are no longer referenced. Programmers do not need to manually manage memory allocation and release as they do in C/C++, which effectively avoids problems such as memory leaks and dangling pointers that can cause programs to crash, greatly improving program robustness and security.

### JDK

JDK stands for Java Development Kit. It is the core of Java development and contains the tools and runtime environment required to develop Java programs.

### IntelliJ IDEA

IntelliJ IDEA is a **professional integrated development environment (IDE)** developed by JetBrains. It is mainly used for Java and Kotlin development and is widely regarded as one of the most powerful development tools in the Java field.

### Hello World

```java
// public: an access modifier indicating that this class is public
// class: the keyword used to declare a class
// HelloWorld: the class name, which must exactly match the file name HelloWorld.java

// public: an access modifier indicating that main is public and can be called by the JVM
// static: indicates that the method belongs to the class and can be called without creating an object

// main: the method name and the entry point of a Java program; execution starts here
// String[]: the parameter type, representing a string array
// args: the parameter name used to receive command-line arguments
public class HelloWorld {
    public static void main(String[] args) {
        // This is a single-line comment
        /* This is a

}
```

### Comments

**Line comment**: A single-line comment begins with two slashes, **//**.

**Block comment**: A multi-line comment begins with **/\*** and ends with **\*/**.

**Documentation comment**: A documentation comment begins with **/\**** and ends with **\*/**. It usually appears before declarations of classes, methods, fields, and so on, and is used to generate code documentation. Tools can extract these comments to generate API documentation such as Javadoc.

#### 2.1.2 Integer Types

For integer types, Java defines only signed integers, so the highest bit represents the sign bit (0 represents a positive number, and 1 represents a negative number). The maximum ranges of the integer types are shown below. A value of type `long` needs an `L` suffix:

```java
byte: -128 ~ 127
short: -32768 ~ 32767
int: -2147483648 ~ 2147483647
long: -9223372036854775808 ~ 9223372036854775807

int a = 1
long a = 1000000000001L
```

#### 2.1.3 Floating-Point Types

Floating-point numbers are decimals. When a decimal is written in scientific notation, the decimal point can “float,” which is why it is called a floating-point number. Values of type `float` require an `f` suffix. Floating-point numbers have very large ranges: `float` can represent values up to 3.4x1038, while `double` can represent values up to 1.79x10308.

```java
float f1 = 3.14f;
float f2 = 3.14e38f; // Scientific notation for 3.14x10^38
float f3 = 1.0; // Error: a value without an f suffix is double and cannot be assigned to float

double d1 = 1.79e308;
double d2 = -1.79e308;
double d3 = 4.9e-324;
```

#### 2.1.4 Boolean Type

The `boolean` type has only two values: `true` and `false`. A Boolean value is always the result of a relational operation. The Java language does not specify how Boolean values are stored. In theory, a Boolean value needs only 1 bit, but the JVM usually represents a `boolean` internally as a 4-byte integer.

```java
boolean b1 = true;
boolean b2 = false;
boolean isGreater = 5 > 3; // The result is true
int age = 12;
boolean isAdult = age >= 18; // The result is false
```

#### 2.1.5 Character Type

The `char` type represents one character. In addition to standard ASCII characters, Java's `char` type can represent a Unicode character.

Note that a `char` uses single quotes (`'`) and contains only one character. It must be distinguished from the string type, which uses double quotes (`"`).

```java
char a = 'A';
char zh = '中';
```

#### 2.1.6 Reference Types

Apart from the primitive types described above, all remaining types are reference types. The most commonly used reference type is the `String` class. A reference-type variable is similar to a pointer in C: internally, it stores an “address” that points to the location of an object in memory.

```java
String s = "hello";
```

#### 2.1.7 Constants

When a variable is declared with the `final` modifier, it becomes a constant. After being initialized when it is defined, it cannot be assigned again; assigning it again causes a compilation error. By convention, constant names are usually written in **ALL CAPS** to distinguish them from variables.

```java
final double PI = 3.14; // PI is a constant
double r = 5.0;
double area = PI * r * r;
PI = 300; // compile error!
```

#### 2.1.8 The `var` Keyword

Sometimes a type name is too long and cumbersome to write. For example:

```java
StringBuilder sb = new StringBuilder();
```

In this case, if you want to omit the variable type, you can use the `var` keyword:

```java
var sb = new StringBuilder();
```

The compiler infers from the assignment that the type of `sb` is `StringBuilder`. To the compiler, the statement:

```java
var sb = new StringBuilder();
```

is automatically treated as:

```java
StringBuilder sb = new StringBuilder();
```

Therefore, using `var` to define a variable merely saves you from writing the type name.

#### 2.1.9 Variable Scope

In Java, multiple statements are enclosed in `{ ... }`. As long as these braces are nested correctly, the compiler can identify the beginning and end of each statement block. A variable defined inside a block has a scope from its definition to the end of that block. Referring to the variable outside its scope causes a compilation error. When defining variables, follow the principle of minimizing scope: define a variable in the smallest possible scope and do not reuse variable names. For example:

```java
{
    ...
    int i = 0; // The scope of i begins here
    ...
    {
        ...
        int x = 1; // The scope of x begins here
        ...
        {
            ...
            String s = "hello"; // The scope of s begins here
            ...
        } // The scope of s ends here
        ...
        // Note: this is a new variable named s.
        // It is different from the variable above because their scopes differ:
        String s = "hi";
        ...
    } // The scopes of x and s end here
    ...
} // The scope of i ends here
```

#### 2.2.3 Type Conversion

**Implicit conversion**

Java automatically performs the type conversion, so you do not need to write conversion code manually. The range relationship among common integer and floating-point types can be remembered as:

```text
byte → short → int → long → float → double
```

Rule 1: **When byte, short, and char participate in an operation, they are first automatically promoted to int.**

Rule 2: When different types participate in an operation, the type with the smaller range is promoted to the type with the larger range before the operation is performed.

**Explicit conversion**

When you want to convert a type with a **larger range to a type with a smaller range**, Java does not convert it automatically; you need to perform an explicit cast.

```text
Format: targetType variableName = (targetType) data;
double a = 3.14;
int b = (int) a;
System.out.println(b);
3
```

Note that when a floating-point number is explicitly converted to an integer, it is **not rounded; the fractional part is discarded directly**. Explicit conversion may cause data loss. If the value exceeds the range, overflow occurs after conversion.

```java
// Convert an integer to a floating-point number
int a = 10;
double b = a;
// Convert a floating-point number to an integer
double a = 3.99;
int b = (int) a; // Discard the fractional part directly
// Conversions among numeric types
int a = 10;
long b = a;
float c = a;
double d = a;
// The other way around:
double a = 10.5;
float b = (float) a;
long c = (long) a;
int d = (int) a;
// Conversions between numbers and strings
int a = 123;
String str1 = String.valueOf(a);     // Number to string

String str2 = "456";
int b = Integer.parseInt(str2);      // String to integer

String str3 = "3.14";
double c = Double.parseDouble(str3); // String to decimal

// Conversions between char and numbers
char ch1 = 'A';
int num1 = ch1;                      // char to int; the result is 65

int num2 = 66;
char ch2 = (char) num2;              // int to char; the result is 'B'
```

#### 2.2.4 Bitwise Operations

| \| | If both corresponding bits are 0, the result is 0; otherwise, it is 1 | (A \| B) gives 61, or 0011 1101 |
| ^ | If corresponding bits are the same, the result is 0; otherwise, it is 1 | (A ^ B) gives 49, or 0011 0001 |

### 2.3 Input and Output

```java
import java.util.Scanner;

public class VariableDemo6 {
    public static void main(String[] args) {
        // ==================== Input ====================
        /*
         * Java input and output
         *
         * Input:
         * 1. Import Scanner
         * 2. Create a Scanner object
         * 3. Use Scanner to receive different types of data
         *
         * Output:
         * 1. System.out.print()
         * 2. System.out.println()
         * 3. System.out.printf()
         */

        // 1. Create a Scanner object
        Scanner sc = new Scanner(System.in);

        // 2. Input an integer
        int num = sc.nextInt();
        System.out.println(num);

        // 3. Input a decimal
        double num2 = sc.nextDouble();
        System.out.println(num2);

        // 4. Input a string (stops at whitespace)
        String str = sc.next();
        System.out.println(str);

        // 5. Input a whole line of text
        String line = sc.nextLine();
        System.out.println(line);

        // 6. Input a single character
        char ch = sc.next().charAt(0);
        System.out.println(ch);

        // 7. Input multiple integers at once
        int a = sc.nextInt();
        int b = sc.nextInt();
        int c = sc.nextInt();

        System.out.println(a);
        System.out.println(b);
        System.out.println(c);

        // 8. Multi-line input
        for (int i = 0; i < 3; i++) {
            String str = sc.nextLine();
            System.out.println(str);
        }

        // 9. An unknown number of input lines
        while (sc.hasNextLine()) {
            String str = sc.nextLine();
            System.out.println(str);
        }

        // 10. Mixing nextInt() and nextLine()
        int age = sc.nextInt();
        // Consume the newline remaining after the integer
        sc.nextLine();
        String name = sc.nextLine();
        System.out.println(age);
        System.out.println(name);


        // ==================== Output ====================

        // 11. print: do not start a new line after output
        System.out.print("Hello ");
        System.out.print("Java");
        // 12. println: start a new line automatically after output
        System.out.println("Hello");
        System.out.println("Java");

        // 13. printf formatted output
        String name = "Zhang San";
        System.out.printf("Name: %s%n", name);


        sc.close();
    }
}
```
